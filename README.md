# Miejsce tylko dla Ciebie

Osobista strona w HTML, CSS i JavaScript. Nie wymaga instalacji ani bibliotek.

## Lokalnie

Otwórz `index.html` w przeglądarce. Pięć zakładek zawiera checklistę, galerię zdjęć, list, słoik ze 100 losowanymi karteczkami i cytaty z wyjaśnieniami.

Zaznaczenia checklisty i dodane zdjęcia są przechowywane w pamięci lokalnej przeglądarki, więc nie są synchronizowane między urządzeniami. Wybrane zdjęcia pozostają na urządzeniu i nie są wysyłane na serwer. Jeśli przeglądarka ograniczy zapis dla plików otwieranych bezpośrednio (`file://`), uruchom stronę przez lokalny serwer HTTP.

## GitHub Pages

Stronę można opublikować bez przebudowywania. W ustawieniach repozytorium wybierz **Pages**, a jako źródło ustaw główną gałąź i katalog `/ (root)`. Po publikacji strona będzie dostępna z innych urządzeń pod adresem `https://<nazwa-użytkownika>.github.io/dla-izy/`.
